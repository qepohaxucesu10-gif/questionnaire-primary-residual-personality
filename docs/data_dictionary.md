# Data dictionary

- `folds/outer_fold_assignments.csv`: publication-only study ID, repeat, fold, train/test role, repeat seed.
- `selected_items/`: fold-level item identifiers and frequencies; no responses.
- `derived_results/`: final aggregate and factor-level outputs; no participant rows.
- `src/`: released preprocessing, architectures, training, reporting, figure, and equivalence-check code.
